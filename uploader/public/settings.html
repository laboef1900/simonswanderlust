Providers

API keys are stored encrypted on this server, one per provider. When a signed-in author uses an AI feature, their browser receives the key of the provider assigned to that feature, in memory only, and calls the provider directly — the server never calls a model. Remote providers may charge for usage.

This is the limit of 20 providers. Delete one to add another.

    The kind cannot change after the provider is added.

    Use case assignments

    Each feature uses the provider assigned here, or the default provider. Story review and excerpts send the active language’s unsaved draft text; photo descriptions send a resized photo and need a model that can read images.

    Test review runs a built-in sample text — never a draft — through the selected story review provider, model, instructions and timeout, using that provider’s stored key. Nothing is saved. Provider usage charges may apply.
