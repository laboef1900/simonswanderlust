Import from WordPress

Import stories from a WordPress export (.xml) as drafts. Published stories are never changed.

Rebuilds drafts from an earlier import and discards your edits to them. Leave off to keep your edits and fetch only missing photos.

The import runs on the server: you can close this page and come back. Running it again later resumes where it left off.

How importing works
  • Photos download one at a time, paced so the old site does not block the import; a large export takes a while.
  • Replacing drafts discards edits to country, region, coordinates, key facts, alt text and body. Use it after changing a story in WordPress and exporting again.
  • A resumed import re-downloads only the photos that are still missing and keeps the edits you made in between.
  • Only one import can run at a time.
