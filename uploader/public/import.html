WordPress Import

Upload a WordPress export (.xml) file to import posts as drafts. Already-published posts are skipped; existing drafts are updated. The import runs on the server — you can close this page and come back to it.

A large export takes a while — photos are downloaded one at a time, deliberately paced so the old site does not cut us off. The import runs on the server: closing this page does not stop it, and reopening it shows where it is. Running it again later is safe and resumes where it left off, re-downloading only the photos that are still missing. Only one import can run at a time.
