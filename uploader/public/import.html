WordPress Import

Upload a WordPress export (.xml) file to import posts as drafts. Published posts are never touched; drafts you already have keep your edits and only pick up photos that are still missing. The import runs on the server — you can close this page and come back to it.

Off (default): drafts from an earlier import are kept as you left them — only photos that are still missing are downloaded and swapped in. On: those drafts are rebuilt from the export and your edits to them are discarded (country, region, coordinates, key facts, alt text, body changes). Use it after changing a post in WordPress and exporting again. Published posts are never touched either way.

A large export takes a while — photos are downloaded one at a time, deliberately paced so the old site does not cut us off. The import runs on the server: closing this page does not stop it, and reopening it shows where it is. Running it again later is safe: it resumes where it left off, re-downloading only the photos that are still missing, and keeps the edits you made to the drafts in between. Only one import can run at a time.
